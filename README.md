## 🧪 Research reproduction

### Edge ET0 Forecasting: Reproducible Benchmark on Raspberry Pi 4B

A from-scratch reproduction of Luo et al. (2025), which benchmarks five deep learning models for reference evapotranspiration (ET0) forecasting on edge devices. Run on synthetic meteorological data with similar statistical properties to the paper's data, across 3 random seeds.

**Headline result:** GRU reaches R² = 0.966 ± 0.001 (n = 3 seeds), MAE = 0.0106, and 0.028 ms/sample latency on CPU.

| Model | Repro R² (mean ± std) | Repro MAE | Params |
|---|---|---|---|
| GRU | 0.966 ± 0.001 | 0.0106 | 40,705 |
| LSTM | 0.965 ± 0.001 | 0.0106 | 53,569 |
| TCN | 0.967 ± 0.002 | 0.0103 | 4,481 |
| L-Transformer | 0.961 ± 0.003 | 0.0110 | 2,337 |
| RNN | 0.949 ± 0.006 | 0.0130 | 1,281 |

**Tech:** Python · PyTorch-style deep learning · Colab · Raspberry Pi 4B target

[View repo →](https://github.com/SarvanshRaj/research-repro-luo2025-et0)
